# Get Licensed: Memon Patta

A mobile card game built in Unity (2D URP), based on the traditional card game **Memon Patta**.

Designed by Khadija Gaffar.

## Project Info

- **Engine:** Unity, 2D Universal Render Pipeline (URP) template
- **Platform target:** Mobile (portrait UI)
- **Solution:** `Get Licensed Memon Patta.slnx`

## Current Progress

The project is in early setup — a blank Unity 2D URP template with no gameplay code yet:

- Default `SampleScene.unity`, URP renderer/global settings, and input actions from the Unity template.
- No custom scripts, prefabs, art, or UI have been implemented.
- Full UI/UX has been designed (mockups) covering: splash/home, practice mode setup, online/rank play lobby, leaderboards, friends, and profile/account screens. Not yet implemented in-engine.
